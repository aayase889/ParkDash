# Experimental Levels 61–66

These are optional, playable Challenge Lab samples. They remain outside the permanent
`ColorSortLevelDatabase`, so the validated Boards 1–60 are untouched. The temporary
**LAB** button jumps directly to Level 61; while testing a sample, the same button reads
**GAME** and returns to the regular board that was open before the lab.

| Level | Sample | Main thinking skill | Runtime status |
|---|---|---|---|
| 61 | The Long Way Out | Trace blocking dependencies before tapping | Playable sample |
| 62 | Four Is Not Five | Avoid an attractive incomplete color match | Playable sample |
| 63 | Valet Exchange | Plan a limited sequence of side-parking entries | Playable sample |
| 64 | Key Color | Complete green to unlock a visible red car | Playable sample |
| 65 | Traffic Schedule | Complete red, green, blue, then yellow | Playable sample |
| 66 | Rush-Hour Finale | Combine locks, order, parking, and limousines | Playable sample |

Recommended progression principle: introduce one visible rule at a time, give the
player one low-pressure level to understand it, then combine it with an older rule.
Difficulty should come from planning depth and scarce space—not hidden information,
random blockers, or a timer.

Use **Color Sort → Validate Experimental Levels 61–66** in Unity to verify the
catalog and runtime sequence. Use **Color Sort → Validate Playable Samples 61–66**
to run the solver against the six rule combinations.
